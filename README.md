# EVA Marketing

Multi-tenant AI marketing platform for Oma Solutions.

## Status

Sprint 01 foundation development in progress. This repository is not production-ready. No customer data, payment processing, social publishing, or production deployments are authorized by the foundation bootstrap.

## Architecture

The approved planning baseline is a TypeScript modular monolith with separate web, API, and worker applications. Implementation is subject to dependency verification, security reviews, and pull-request acceptance gates.

See the forthcoming Sprint 01 foundation pull requests for local setup instructions and test commands.
